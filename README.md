# Galinhas Mutantes

Jogo 2D topdown vertical (Godot 4.3) de coleção e criação de galinhas.
Ciclo: plantar -> colher alimento -> criar até adulta -> cruzar -> chocar -> nova espécie.

- Genética: `scripts/genetics.gd` (probabilidades no topo do arquivo).
- Jogo: `scripts/main.gd`.
- Build HTML: GitHub Actions (`.github/workflows/web.yml`) publica no GitHub Pages.
